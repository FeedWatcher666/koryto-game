# CLEAN TEST.4 — výhoda, nevýhoda a fyzický hod

TEST.4 rozšiřuje čistý JavaScriptový d20 engine bez přidání Pythonu nebo externí runtime závislosti.

## Pravidla

- běžný hod: `1d20`,
- výhoda: `2d20kh1`, ponechá se vyšší hod,
- nevýhoda: `2d20kl1`, ponechá se nižší hod,
- současná výhoda a nevýhoda se navzájem ruší,
- zdroj režimu je viditelný ještě před kliknutím.

Syntaxe je inspirována běžnými D&D dice enginy včetně projektu `avrae/d20`, ale implementace je původní, klientská a offline.

## Vizuální polish

- dvě fyzicky oddělené d20 při výhodě nebo nevýhodě,
- čísla přímo na trojúhelníkových stěnách,
- ponechaná a vyřazená kostka jsou jasně označené,
- let přes podložku, tvrdý náraz, menší odskok a dojezd,
- opotřebený bakelitový materiál,
- dynamické osvětlení, textura hran a pohyblivý stín,
- oddělený zvuk chrastění, dopadů a výsledku.
