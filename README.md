# Koryto v0.16.8 TEST.1

Hratelný offline test sjednoceného kampanového UI.

## Spuštění

Rozbalte ZIP a otevřete `index.html`.

## Nově převedené části

- nový úvodní briefing třináctidenní kampaně,
- tvorba kandidáta s živým náhledem,
- tři výchozí motivace s viditelnými dopady,
- šest politických povolání se schopností a atributy,
- pixel-cartoon mapa Dolních Vejprnic,
- funkční štáb a nábor,
- přehled a detail kauz,
- detail osmi lokalit,
- události a výsledky rozhodnutí,
- denní uzávěrka před ukončením dne,
- veřejná debata a taktické karty,
- volební noc a patnáctimandátový přehled,
- koaliční salonek, nabídky a živý log vyjednávání,
- responzivní desktopové a mobilní rozhraní.

## Doporučený test

1. Na úvodní obrazovce zkontrolujte briefing, parametry kampaně a přechod do tvorby kandidáta.
2. Změňte jméno, motivaci a všech šest politických povolání; živý kandidátní list se musí okamžitě aktualizovat.
3. Vstupte do hry a projděte prolog.
4. Otevřete `Kauzy`, vyzkoušejte filtry a detail aktivní kauzy.
5. Přejděte z detailu kauzy do lokality a proveďte rozhodnutí.
6. Na mapě otevřete `Ukončit den`, zkontrolujte přehled a potvrďte další den.
7. Spusťte veřejnou debatu a odehrajte několik taktických karet.
8. Dokončete volby a projděte koaličním vyjednáváním.
9. Ověřte celý tok také při šířce mobilního telefonu.

Podrobný popis iterace je v `docs/v0.16/v0168-onboarding.md`.
