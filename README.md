# Koryto

Satirické české politické RPG o třináctidenní komunální kampani v Dolních Vejprnicích.

## Aktuální testovací verze

**v0.14.8 TEST.10 – Pixel-artový vizuální systém**

Verze převádí celé rozhraní do jednotného desktopového a mobilního pixel-artového stylu. Nejde o statický screenshot: nové obrazovky čtou skutečný stav questů, členů štábu, mocenských domén, soupeřovy strategie, debaty, voleb a paměti kampaně.

### Hlavní změny

- horní HUD se dnem, důvěrou, vlivem a penězi,
- responzivní mapa Dolních Vejprnic,
- spodní herní navigace,
- obrazovky Kauzy, Štáb, Mapa vlivu, Debata, Volby a Archiv,
- pixelové rámy, panely, portréty a stavové značky,
- vysoký kontrast, větší text a omezení animací,
- jednoduché lokální zvuky rozhraní,
- desktop, tablet a mobil bez změny herní logiky.

## Spuštění

Rozbalte ZIP a otevřete `index.html`. Hra funguje offline bez instalace.
