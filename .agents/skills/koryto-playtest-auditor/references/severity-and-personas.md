# Severity and player lenses

## Severity

- **P0** — data loss, broken offline launch, security issue, or campaign-wide corruption.
- **P1** — reachable soft lock, wrong rule resolution, duplicated consequence, broken save/load, or inaccessible main path.
- **P2** — misleading UI, significant mobile blocker, route-specific state leak, missing consequence, or major pacing/agency failure.
- **P3** — polish, wording, minor visual hierarchy, animation timing, or low-impact inconsistency.

## Player-lens questions

### Impatient player

- Is the current objective visible without scrolling through unrelated panels?
- Does each action explain what the player is trying to achieve?
- Does the game distinguish information from a clickable choice?

### Role-player

- Does class, origin, morality, companion, or item change available behavior?
- Does the game react later rather than only changing a number immediately?

### System breaker

- Can the same reward or consequence be committed twice?
- Can reload restore every actionable transient choice?
- Can complication and critical outcomes still reach an ending?

### Small-mobile player

- Is there horizontal overflow?
- Are controls at least comfortably tappable?
- Is focus visible?
- Does the dice overlay explain why one or two dice are rolled?
- Can animation be skipped or reduced?
